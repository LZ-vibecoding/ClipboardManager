# 剪贴板历史管理器 — 需求规格说明书

> 版本: v1.0  
> 最后更新: 2026-06-04

---

## 1. 项目概述

### 1.1 产品定位
Windows 11 轻量级剪贴板历史管理工具，解决 Windows 原生剪贴板只能保存一条内容的痛点。

### 1.2 目标用户
日常办公用户，需要频繁复制粘贴文本和图片，希望找回历史复制记录。

### 1.3 核心原则
- **本地优先**：所有数据存储在本地，不联网
- **轻量高效**：低内存占用（空闲 < 15MB），CPU 占用 0%
- **即时响应**：热键弹出窗口 < 200ms，搜索过滤 < 50ms
- **稳定可靠**：数据不丢失，崩溃可恢复

|----|------|--------|
| NF01 | 启动到托盘出现 | < 500ms |
| NF02 | 热键响应到窗口显示 | < 200ms |
| NF03 | 剪贴板捕获延迟 | < 100ms |
| NF04 | 搜索过滤 (200 条目) | < 50ms |
| NF05 | 空闲 CPU | 0%（事件驱动，不轮询） |
| NF06 | 空闲内存 | < 15MB |
| NF07 | 运行中内存 | < 80MB（连续运行 72h） |
| NF08 | 数据安全 | SQLite WAL 模式，崩溃最多丢最后一条 |
| NF09 | 单实例 | 只允许运行一个实例 |

## 4. 边界场景

| 场景 | 预期行为 |
|------|----------|
| 复制相同内容两次 | 去重，条目"浮"到列表顶部，不重复插入 |
| 程序崩溃 | WAL 模式保证数据完整性，启动时自动检测 |
| 重复启动 | 通知已有实例显示窗口，新实例退出 |
| 管理员窗口粘贴 | 普通窗口自动粘贴；管理员窗口提示手动 Ctrl+V |
| 磁盘空间不足 | 自动清理最旧的非固定条目图片，重试保存 |
| 数据库损坏 | 启动时检测并尝试修复；修复失败则备份后重建 |
| 超大图片 (> 50MB) | 仅生成缩略图，不保存原图 |
| 连续快速复制 | 60ms 防抖合并，避免频繁写入 |
| 与其他软件热键冲突 | 显示友好提示，建议用户修改热键 |
