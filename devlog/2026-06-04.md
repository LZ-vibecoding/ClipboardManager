**Phase 1 — 剪贴板监控 + 全局热键**

4. **NativeMethods.cs** — 全部 Win32 P/Invoke 声明：
   - SetClipboardViewer / ChangeClipboardChain / SendMessage（剪贴板查看器链）
   - GetClipboardSequenceNumber（序列号去重）
   - RegisterHotKey / UnregisterHotKey（全局热键）
   - GetForegroundWindow / SetForegroundWindow / AttachThreadInput（窗口焦点管理）
   - GetCursorPos / MonitorFromPoint / GetMonitorInfo / GetDpiForMonitor（多屏幕 DPI）
   - SendInput + INPUT/KEYBDINPUT/InputUnion（模拟按键）
   - 常量：MOD_CONTROL, MOD_SHIFT, MOD_NOREPEAT, VK_V, WM_DRAWCLIPBOARD 等

5. **ClipboardMonitor.cs** — 剪贴板三重去重监控：
   - Win32 SetClipboardViewer 注册为剪贴板查看器
   - 去重层 1：GetClipboardSequenceNumber() 序列号变化时再处理
   - 去重层 2：80ms 防抖（Task.Delay），过滤 Word/Excel 等一次复制多次通知
   - 去重层 3：SHA256 内容哈希（最终去重）
   - STA 线程读取：Dispatcher.Invoke 确保剪贴板在正确线程访问
   - 文本：Clipboard.GetText(UnicodeText)；图片：Clipboard.GetImage() → PngBitmapEncoder

6. **HotkeyService.cs** — 全局热键 Ctrl+Shift+V：
   - HwndSource 隐藏窗口 + RegisterHotKey(9001, MOD_CONTROL|MOD_SHIFT, VK_V)
   - WndProc 处理 WM_HOTKEY → HotkeyPressed 事件
   - MOD_NOREPEAT 防止长按重复触发

---

**Phase 2 — 数据存储 (SQLite + 图片)**

7. **DatabaseContext.cs** — SQLite 初始化：
   - WAL 模式 + synchronous=NORMAL + busy_timeout=5000
   - 建表 `clipboard_items` (id, content_hash, type, text_content, image_path, thumbnail_path, is_pinned, created_at, updated_at)
   - 建表 `settings` (key, value) 用于 KV 配置存储
   - 3 个索引：idx_created_at, idx_content_hash, 唯一索引 idx_hash_type
   - 连接池开启：Pooling=true, Cache=Shared

8. **StorageService.cs** — 完整 Dapper CRUD：
   - InsertAsync · GetByHashAsync · GetRecentAsync(搜索LIKE) · UpdateTimestampAsync
   - SetPinnedAsync · DeleteAsync · GetCountAsync · GetTrimCandidatesAsync

9. **ImageService.cs** — 图片管理：
   - 存储路径 `%LocalAppData%\ClipboardManager\images\{hash[..2]}\{hash}.png`
   - 缩略图 120x120 生成（TransformedBitmap + PngBitmapEncoder）
   - 超大图片 >2000px 等比缩放后保存；>50MB 仅生成缩略图
   - 删除时清理文件及空父目录

10. **SettingsService.cs** — 设置以 JSON 存储在 SQLite settings 表中，内存缓存减少读 DB

11. **ClipboardManagerService.cs** — 总协调器串联监控→存储→UI

---

**Phase 3 — 历史记录窗口**

12. **RelayCommand.cs** — 通用 ICommand 实现（非泛型 + 泛型版本）

13. **Converters.cs** — 6 个值转换器（类型图标、固定图标、可见性转换、图片路径→ImageSource）

14. **HistoryViewModel.cs** — 历史窗口逻辑：
   - 数据按"固定项→今天→昨天→更早"分组
   - 搜索 300ms 防抖
   - PinCommand · DeleteCommand · PasteCommand
   - 监听 HistoryChanged 事件自动刷新

15. **HistoryWindow.xaml** — 420×600 无边框窗口：
   - 搜索框 · 分组列表 · 条目卡片（类型图标+内容预览+时间+操作按钮）
   - 圆角 + 阴影效果 · 半透明背景
   - ModernStyles.xaml 统一样式

16. **HistoryWindow.xaml.cs** — 窗口行为：
   - ShowAtBottomRight()：DPI 感知多屏幕定位（Win32 物理像素 ÷ DPI缩放 → WPF DIP）
   - GetMonitorScale()：GetDpiForMonitor → scale = dpiX / 96.0
   - 失焦自动关闭 · Esc 关闭 · Ctrl+F 聚焦搜索

---

**Phase 4 — 粘贴功能**

17. **PasteService.cs** — SendInput 模拟 Ctrl+V：
   - 按键序列：Ctrl Down → V Down → V Up → Ctrl Up
   - KEYEVENTF_KEYUP 标志控制按下/释放
   - 调用方重试：剪贴板写入失败时 5 次重试（CLIPBRD_E_CANT_OPEN）

18. **ClipboardManagerService.PasteAsync** — 粘贴完整流程：
   - 文本：Clipboard.SetText()
   - 图片：BitmapImage 从文件加载 → Clipboard.SetImage()
   - 图片文件不存在时降级尝试缩略图
   - 50ms 等待 → SimulatePaste() → 更新时间戳

19. **双击粘贴** — Border.MouseDown 事件检测 ClickCount>=2 → 触发 PasteCommand

---

**Phase 5 — 设置功能**

20. **AutoStartService.cs** — 开机自启注册表管理：
   - 路径 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
   - 键名 `ClipboardManager`，值为可执行文件全路径
   - SetEnabled() · IsEnabled()

21. **SettingsViewModel.cs** — 设置窗口逻辑：
   - MaxItemCount · AutoStartWithWindows · MonitorImages/MonitorText · ThumbnailSize · ImageQuality
   - LoadAsync() 从数据库加载 · SaveCommand 保存并应用

22. **SettingsWindow.xaml** — 设置界面：
   - 存储：条目数量滑块(20-1000) · 文本/图片监控复选框 · 开机自启开关
   - 图片：缩略图尺寸滑块 · 图片质量滑块
   - 保存/取消按钮 · 版本信息

23. **集成到 App.xaml.cs**：
   - 托盘菜单"设置"选项 → OnRequestShowSettings()
   - 启动时同步 AutoStart 设置
